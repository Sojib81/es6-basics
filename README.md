# es6-basics

Short examples of the ES6 features used in React. Run any file with `node <file>`.

| File | Topic |
|---|---|
| `variable.js` | `var`, `let`, `const` |
| `arrowFunctions.js` | Arrow functions |
| `classes.js` | Classes and inheritance |
| `arrayMethods.js` | `.map()` |
| `destructuring.js` | Array and object destructuring |
| `spreadOperator.js` | Spread and rest (`...`) |
| `ternaryOperator.js` | Ternary operator |
